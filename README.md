# Hoop - Someone to go with 🚀

Hoop is a premium companion booking platform where users can book verified companions for outings like weddings, coffee dates, and gigs. This project was originally a static HTML prototype and has been transformed into a full-stack Next.js application using React and Prisma ORM.

---

## 🛠 Tech Stack
- **Frontend:** Next.js (App Router), React, Vanilla CSS (preserving the original design)
- **Backend:** Next.js API Routes (`/api/companions`, `/api/bookings`)
- **Database:** SQLite (local database for fast development)
- **ORM:** Prisma ORM

---

## 💻 Local Deployment Guide

Follow these steps to get the application up and running on your local machine.

### 1. Prerequisites
Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/en/) (v18.0.0 or higher recommended)
- npm (comes with Node.js)

### 2. Installation
First, clone the repository or navigate to the project folder, then install the dependencies:

```bash
# Navigate to the project directory
cd Hoop

# Install all required npm packages
npm install
```

### 3. Environment Variables
The project requires a `.env` file to configure the database and other secrets. 
A sample file is already provided. If it's missing, create a `.env` file in the root directory and add:

```env
# Server Configuration
PORT=3000
NODE_ENV=development

# Database Configuration (SQLite)
DATABASE_URL="file:./dev.db"

# Authentication & Security
JWT_SECRET="super-secret-jwt-key-replace-me-in-production"
JWT_EXPIRES_IN="7d"

# Third-Party APIs (To be implemented)
TWILIO_ACCOUNT_SID="your_twilio_account_sid"
TWILIO_AUTH_TOKEN="your_twilio_auth_token"
TWILIO_PHONE_NUMBER="your_twilio_phone_number"
```

### 4. Database Setup
We use Prisma with a local SQLite database (`dev.db`). To initialize the database and seed it with the initial companion data, run the following commands:

```bash
# Push the Prisma schema to the database (creates tables)
npx prisma db push

# Seed the database with the initial Companion profiles
node prisma/seed.js
```
*Note: The seed script will populate the database with the original 4 profiles so the 3D rotating hero stack functions correctly.*

### 5. Running the Application
Once the database is ready, you can start the Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📁 Project Structure

Here is a quick overview of where everything lives:
- `src/app/page.js`: The main frontend React component (contains the UI, state, and API fetch logic).
- `src/app/globals.css`: The original vanilla CSS preserving the aesthetic and animations.
- `src/app/api/`: Contains the backend API routes (e.g., `companions/route.js`, `bookings/route.js`).
- `prisma/schema.prisma`: The database schema definition.
- `prisma/seed.js`: The script that populates the database with initial companion data.
- `dev.db`: The local SQLite database file generated by Prisma.
